* Known gaps in what's built
- No splits or windows (multiple buffers exist, one is visible at a time)
- Full tree-sitter reparse per edit, on a worker thread (no incremental parse)
- No text objects (`ciw`, `di(`) and only the unnamed register
- Lisp can push commands and be called from keys, but cannot yet *read* buffer state
- `M-x` offers zero-argument commands only, since it calls `(name)` with no args

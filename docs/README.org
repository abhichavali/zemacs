#+TITLE: zemacs — the Lisp reference
#+SUBTITLE: a Common Lisp machine that edits text

zemacs is an editor whose configuration language is a live Common Lisp image.
=runtime/init.lisp= is not a settings file that a program reads — it is a
program, loaded into an ECL image that runs for as long as the editor does, and
every function it defines can be named by a key binding, a dashboard item or
=M-x=.

This directory is the reference for that image: what it can reach, what it
cannot, and why the line is where it is.

* The thirty-second version

Everything lives in the =ZEMACS= package. Your config file starts with
=(in-package :zemacs)=; anything the editor evaluates for you (a key binding,
=M-x=, the =C-c= evaluator, the scratch buffer) is read with =*package*= already
bound to =ZEMACS=, so you never have to qualify a name.

#+begin_src lisp
(in-package :zemacs)

;; Read the editor.
(point)                     ; => 42
(region-text)               ; => "the selection", or NIL
(major-mode)                ; => "org-mode"

;; Write the editor.
(insert "hello")
(replace-region 0 5 "HELLO")
(set-font-size 22)

;; A command is a zero-argument function. That is the whole mechanism.
(defun surround-region (left right)
  (let ((r (region)))
    (when r
      (replace-region (car r) (cdr r)
                      (concatenate 'string left (region-text) right)))))

(defun org-bold () (surround-region "*" "*"))
(define-key "org-mode" "SPC m b" "org-bold")
#+end_src

* Where the code is

| Path                         | What is in it                                                        |
|------------------------------+----------------------------------------------------------------------|
| =crates/lisp/src/shim.c=       | The C bridge, and the Lisp library installed at boot.                |
| =crates/lisp/src/lib.rs=       | The Rust side of every primitive; the module docs are the contract.  |
| =crates/core/src/query.rs=     | The readers. Adding one is one arm of one =match=.                     |
| =crates/core/src/evil.rs=      | The built-in verbs a key binding can name, in =run_action=.            |
| =runtime/init.lisp=            | The shipped config. Ordinary Lisp, all of it replaceable.            |
| =runtime/modes/=               | Major and minor mode machinery, written in Lisp on top of one hook.  |

The tests are executable documentation: =crates/lisp/tests/api.rs=, =eval.rs=,
=modes.rs= and =prompt.rs= each boot a real image against a real editor and
assert on what comes out. When this reference and those tests disagree, the tests
are right.

=prompt.rs= is also the only place the *whole* route a prompt's answer takes is
written down as code: it plays the part of the main loop, and if the two ever
disagree it is the test that notices.
